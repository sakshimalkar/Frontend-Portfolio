## 🚀 Run Locally

```bash
# Clone the repository
git clone https://github.com/sakshimalkar/Frontend-Portfolio.git

# Navigate into the folder
cd Frontend-Portfolio

# Install dependencies
npm install

# Start the development server
npm start
```
